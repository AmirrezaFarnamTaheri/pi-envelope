## Cross-project ownership and conflicts

1. **Shell:** Tersio retains exclusive RTK rewrite ownership. MasuRii/Chisle/mcowger provide compaction algorithms and fixtures, not three installed `tool_result` owners. Preserve bytes and build/test failures.
2. **Context:** exactly one native `context` event mutator; ACP blocks, checkpoint pruning and Boomerang-style handoff must run as selectable internal strategies, never independently installed. Provider cache costs must be measured, not inferred from byte savings.
3. **Code:** one parser/graph index. New opt-in TS/JS pre-write syntax gate lives in `extensions/envelope/mutation-guard.mjs`. The syntax guard itself does **not** claim multi-language Tree-sitter or LSP verification. A separate v0.9.0 opt-in LSP stdio adapter supplies file-level diagnostics and preview-gated rename. Neither guards against arbitrary concurrent filesystem changes.
4. **Prompt policy:** one bounded prompt section with Caveman/Ponytail/Chisle rules; no automatic strict-purge deletion of AGENTS.md, skills, project rules, safety warnings or tool schemas.
5. **Autonomy:** native workflow ledger owns workers/claims and Git worktree handoffs. OpenRig is an optional external coordination adapter; never assume blanket approval bypass or mandatory tmux daemon.
6. **Indexing:** large Rust/Neo4j/Postgres/Redis stacks are not mandatory native dependencies. OCI, CodeGraph, Memex and similar services should expose optional health-checked APIs with fallback.

## High-value gap assessment after v0.9.0

### Verified native features

- Bundled Tersio extension entrypoints and Ponytail skills (runtime installation still requires Tersio dependency).
- Conservative, line-preserving bash output compaction (including mixed anchored output), exact raw FTS retrieval and checkpoint-based recoverable context projection.
- Shared JS/TS syntax/symbol/import graph, task DAG with review and Git worktree handoffs, local numeric observability and offline benchmark.
- **New:** opt-in `write`/`edit` syntax preflight using Pi’s current batched `edits[]` shape. Default off, bounded diagnostics, fails open on ambiguity.

### Important features **not yet extracted**

- MasuRii streaming execution sanitization, read-specific AST filtering and partial-stream rewriting. v0.8.0 only handles complete `tool_result` text and keeps anchored records intact.
- Pi Shazam full language-server lifecycle/supervision, formatting, rich refactoring and multi-language LSP test matrix. v0.9.0 provides only an opt-in stdio diagnostic broker and conservative rename transaction, with fake-server protocol tests but no production server verification.
- Tree-sitter nine-language S-expression query/capture broker; syntax guard currently TS/JS only.
- CodePilot commit-pinned PR head verification, docs/code contradiction detection and test graph.
- RepoPilot Python MRO-aware call resolution with explicit confidence and unresolved evidence.
- Repomap incremental content-hash parse caching and full reference-weighted PageRank, not just static-import score.
- Billion Context versioned hierarchical ACP blocks and crash-replay; Context Prune append-only frontier and controlled summarize calls.
- Context Mode chunked BM25/RRF search and optional sandbox execution.
- OpenRig messaging/team collaboration; GSD autonomous milestone/auto-loop and cross-agent handoff.
- Memex local cross-agent transcript search; Pi Context View prompt injection visualization.
- Pi Purge exact-guarded prompt experiments and user-facing package collision doctor.

## Source, licensing and validation rules

The matrix links to the original repositories. Prior phase docs sometimes say `practice-adapted`; that denotes **independent behavior inspired by an upstream idea**, not copied upstream code. Before any source-level copy: pin the exact commit, inspect that file’s license and third-party notices, retain attribution where necessary, run focused red-green tests, and measure impact. README or API metadata reachability does not itself prove all history, dependencies or code paths were audited. The unified extension is not yet a production-validated replacement for all 33.

Future prioritization should be based on measurable correctness and latency, not feature count. Do not add a second hook owner where one well-tested native module can supply the behavior.

## Multi-language parser evidence

The previously pinned 33 repositories are unchanged. A new native, **opt-in** `python3 -I -S`/`ast` and `go run`/`go/parser` layer extends the existing shared TS/JS index with structural symbols, syntax verification and conservative local import evidence. This reflects analysis patterns from RepoPilot, Code Graph Pilot, Pi Tree-sitter and Pi Repomap, but is **not** an integration of those projects' native parsers or their advanced call graphs. Neither grammar/WASM Tree-sitter nor MRO-aware call inference is claimed. `envelope_code_rename` continues to reject Python and Go because its transaction validator is TS-specific.

The host now offers `npm run smoke:runtime` to check pinned Tersio resources and Pi RPC command discovery without an LLM call, and `npm run smoke:lsp-real` for genuine clangd C diagnostics. The former is blocked by missing Pi and Tersio here; the latter passes. A C LSP smoke does not imply CodeIndex indexes C or that semantic rename is verified against a production server.
